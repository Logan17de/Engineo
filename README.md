# Engineo

**Command complex projects.**

Engineo is a free, modern project planning and controls platform for teams running complex work across construction, infrastructure, energy, engineering, manufacturing, shutdowns, and other schedule-intensive industries.

Engineo is not designed as a clone of any incumbent product. It is being built from first principles around the jobs professional planners, schedulers, project managers, cost engineers, resource managers, contractors, and owners need to accomplish.

## Product principles

1. **Deterministic core** — schedule, cost, and earned-value mathematics are computed by tested engines, never guessed by AI.
2. **AI as a copilot** — AI explains, proposes, audits, and automates; deterministic services validate every material schedule change.
3. **Professional depth without legacy UX** — support serious project controls while making common workflows dramatically easier.
4. **Open data** — users can export their project data and integrate through documented APIs.
5. **Industry-flexible** — construction is an important use case, not a hard-coded boundary.
6. **Free core product** — advanced project controls should be accessible to teams that cannot justify expensive enterprise software.

## Planned capabilities

- WBS, activities, milestones, dependencies, constraints, and calendars
- CPM scheduling, float, critical/longest path, and progress updates
- Baselines and schedule variance analysis
- Resources, roles, capacity, assignments, and resource leveling
- Costs, expenses, forecasting, and earned value management
- Multi-project programs and portfolio visibility
- Dashboards, reporting, audit history, permissions, and collaboration
- Import/export interoperability
- AI schedule creation, audits, delay explanations, recovery scenarios, and risk analysis
